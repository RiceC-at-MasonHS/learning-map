# Learning Map

A tech tree for a course: zoom out to the standards, zoom in to the commands you type today.
Teachers plan a shared route through it; students see the lighthouses ahead and choose trails between sync points;
evidence of learning stays on the school's own machine.

Starting with **AP Cybersecurity**. Successor to [learner-profile-flowchart](https://github.com/crice009/learner-profile-flowchart).

**Status:** Phase 0 — curriculum data model. See [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md).
